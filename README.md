# House Floor Stone Planner

Interactive 3D planner for our house (ground + first floor) to choose Indian floor stones room by room.

- Open `index.html` in any browser (phone or laptop). Needs internet to load the 3D library.
- Click a room (or use ☰ Options), pick a stone, colour and finish.
- 🚶 Walk mode: round joystick or arrow keys, climb the stairs between floors.
- Material list with areas and tile counts updates as you choose.

Plans: igloo constructions GF.pdf / FF.pdf. Floor height 11 ft, doors 4×8 ft, windows 3×5.5 ft, 3 ft walkway around first floor.
